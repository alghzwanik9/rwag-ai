# دليل العرض الحي للجنة التحكيم — Rwaq AI (4-Minute Live Demo Runbook)

دليل تنفيذي مختصر ومباشر لتشغيل واستعراض **منصة رِواق (Rwaq AI)** أمام لجنة التحكيم في **4 دقائق** بثبات كامل وبدون أي مفاجآت تقنية.

---

## 1. فحوصات ما قبل العرض (30 دقيقة قبل التحكيم)

نفّذ الأوامر التالية من مجلد المشروع الرئيسي `d:\DEV\ACTIVE\rwaq-ai`:

### أ) التحقق من مفاتيح الـ API وحصص الاستخدام (Quota)
- تأكد من صلاحية `GEMINI_API_KEY` و `FAL_KEY` في `.env` (و `FAL_KEY` في `frontend/.env.local`) — **دون طباعة أي مفاتيح على الشاشة**.
- تأكد من عدم استهلاك حصة Gemini المجانية قبل بدء العرض مباشرة.

### ب) تشغيل حزمة الاختبارات الآلية وبناء نسخة الإنتاج
```powershell
# 1. اختبارات الخادم والتدقيق المكاني (pytest)
.\.venv\Scripts\python.exe -m pytest tests/ -v

# 2. اختبارات عقود الواجهة الأمامية
node --experimental-strip-types tests/verify_frontend_contracts.mjs

# 3. بناء نسخة الإنتاج المستقرة للواجهة الأمامية
cd frontend
npm run build
cd ..
```

### ج) التحقق من صحة قاعدة المتجهات `LanceDB`
بعد تشغيل الخادم الخلفي، افتح أو نفّذ:
```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/db-check
```
**النتيجة المتوقعة:** `"status": "healthy"` وظهور جدول `ikea_catalog` (`3,694` سجل) وجدول المعايير المعمارية.

---

## 2. أوامر التشغيل الرسمية للعرض الحي (Production Startup)

استخدم **نسخة الإنتاج (`npm run start`)** بدلاً من `npm run dev` لضمان سرعة تنقل فورية دون إعادة ترجمة الصفحات أثناء العرض.

**النافذة 1 — خادم FastAPI (من الجذر):**
```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

**النافذة 2 — خادم Next.js (الإنتاج):**
```powershell
cd frontend
npm run start
```

- الواجهة الأمامية: `http://localhost:3000`
- خادم FastAPI: `http://127.0.0.1:8000`

---

## 3. تهيئة المصادقة ووصول المحكمين (`NEXT_PUBLIC_DEMO_MODE`)

لإتاحة الدخول الفوري إلى `/studio` و `/studio2d` أمام اللجنة دون التوقف عند شاشة تسجيل الدخول:
1. في `frontend/.env.local` اضبط:
   ```env
   NEXT_PUBLIC_DEMO_MODE=true
   ```
2. أعد بناء الواجهة (`cd frontend && npm run build`) قبل `npm run start`.
3. **ملاحظة أمنية مهمة للجنة:** تفعيل `NEXT_PUBLIC_DEMO_MODE=true` يتجاوز فقط وسيط Clerk على واجهة `/studio` و `/studio2d` لأغراض العرض المحلي؛ بينما تبقى نقطة حفظ المشاريع الخادمية (`POST /api/projects/save`) محمية بالكامل بمصادقة Clerk. إذا أردت استعراض `ProjectsModal` والحفظ السحابي في `Supabase`، سجّل الدخول مسبقاً بحساب العرض قبل بدء الجلسة.

## 4. سيناريو العرض الحي خطوة بخطوة (4 دقائق)

### `0:00 – 0:30` | الصفحة الرئيسية (`/`)
- افتح `http://localhost:3000`.
- قدّم القيمة الجوهرية في جملتين: *«رواق يحوّل الوصف النصي أو الصورة المرجعية إلى مشهد 3D تفاعلي في المتصفح خلال ثوانٍ، مع تدقيق هندسي حتمي وفق نيوفرت وكود البناء السعودي وتسعير حي بالريال السعودي»*.

### `0:30 – 1:15` | معرض القوالب الجاهزة (`/maarad`)
- انتقل إلى `/maarad` لاستعراض **6 تصاميم جاهزة للتعديل بأسعارها الفعلية بالريال**:
  - `majlis-andalus` (`13,070 SAR`)
  - `living-japandi` (`8,725 SAR`)
  - `office-exec` (`5,050 SAR`)
  - `studio-minimalist` (`5,030 SAR`)
  - `dining-terrace` (`4,495 SAR`)
  - `bedroom-serenity` (`4,135 SAR`)
- اضغط لفتح **`living-japandi`** أو **`majlis-andalus`** مباشرة داخل `/studio` لإظهار سرعة التحميل الفورية باستخدام المجسمات المحلية (`>1 MB GLB`) وفيزياء `Rapier 2.2.0`.

### `1:15 – 2:30` | الاستوديو التفاعلي والتوليد بالذكاء الاصطناعي (`/studio`)
1. **التوليد النصي المباشر (`/api/generate-room`):** انسخ والصق الأمر العربي التالي في صندوق التوليد:
   ```text
   صمم غرفة معيشة سعودية عصرية بأبعاد 5.5 × 4.5 متر بإضاءة صباحية دافئة، جدران بيج حجري وأرضية خشب بلوط، تشمل كنبة رئيسية وطاولة قهوة ووحدة تلفاز وكرسي قراءة ونباتات داخلية مع مراعاة ممرات الحركة.
   ```
2. **التخصيص الحي:**
   - دوّر الكاميرا `360°` وأظهر النوافذ الفعلية (`RealRoom`) والتصاق القطع بالأرضية (`t_y = 0.0`).
   - بدّل الإضاءة (`Morning → Rainy → Midnight`) وغيّر لون الجدار من `MaterialPalette` لتأكيد التحديث الفوري بمعدل 60FPS دون أي رندرة خادمية.
3. **المحادثة التوليدية الحية (`/api/v1/chat`):** انسخ والصق الأمر التالي في المساعد الذكي:
   ```text
   أضف كرسي استرخاء جانبي خشبي وخزانة جانبية متناسقة مع الحفاظ على انسيابية الممرات.
   ```

### `2:30 – 3:15` | التدقيق المكاني الحتمي، التسعير، وتصدير PDF
1. اضغط على **التدقيق المكاني (`SpatialAuditModal`)** لاستدعاء `POST /api/v1/spatial-audit`:
   - اعرض الدرجة المحسوبة رياضياً (`[50–100]`)، نسبة الإشغال (`15%–45%`)، خلوص الكنبة وطاولة القهوة (`0.30–0.65م`)، مسافة التلفاز (`>=1.5م`)، وفحص تداخل `2D AABB` مع التوصيات العربية.
2. افتح قائمة الميزانية بالريال:
   - اعرض السعر الإجمالي الحي، رابط الشراء المباشر (`store_url`)، وزر **بدائل الميزانية** (`POST /api/recommendations/alternatives`).
   - اضغط **`QuoteExportButton`** لتصدير عرض السعر كملف **PDF** احترافي (أو `PrintReport` لجدول المواد BOM).
   - افتح **`ProjectsModal`** لإظهار الحفظ السحابي في `Supabase` (عند تسجيل الدخول عبر `Clerk`).

### `3:15 – 4:00` | مكتبة الكتالوج (`/library`) واستوديو 2D (`/studio2d`)
1. افتح `/library` لإظهار البحث الدلالي في فهرس `LanceDB` (`3,694` سجل إيكيا) ورمز QR لمعاينة الواقع المعزز (`/ar`).
2. افتح `/studio2d` لاستعراض توليد اللقطات المعمارية ثنائية الأبعاد عبر `Fal.ai Flux Schnell` باستخدام الأمر:
   ```text
   مجلس سعودي معاصر بإضاءة طبيعية ناعمة، حجر ترافرتين دافئ وخشب جوز طبيعي وتفاصيل معمارية هادئة
   ```

## 5. خطة الطوارئ والعمل دون اتصال (Offline & Emergency Fallback)

| السيناريو الطارئ | الإجراء الفوري المضمون |
| :--- | :--- |
| **انقطاع أو ضعف الإنترنت في القاعة** | محرك 3D في `/studio` و `/maarad` يعمل **100% دون اتصال** بفضل إضاءة `Lightformer` المحلية و10 مجسمات `GLB` مخزنة محلياً (`frontend/public/assets/`)، كما يعمل التدقيق المكاني `audit_spatial_layout` وقاعدة `LanceDB` محلياً بالكامل! افتح قوالب `/maarad` واستعرض التعديل الفوري والتدقيق المكاني وتصدير PDF دون الحاجة لأي API خارجي. |
| **تجاوز حصة Gemini أو Fal.ai (`HTTP 429`)** | استعرض قوالب `/maarad` الجاهزة + التعديل الفوري للخامات والإضاءة + التدقيق المكاني الحتمي + `/library` + تصدير عرض السعر PDF. |
| **مشكلة في عرض PowerPoint** | افتح [rwaq_presentation_deck.html](../rwaq_presentation_deck.html) مباشرة في Chrome/Edge (اضغط `F11` للعرض الكامل أو `Ctrl+P` لحفظ نسخة PDF عالية الدقة بمقاس `16:9`). |
| **تذكير قبل دخول القاعة** | جهّز مسبقاً فيديو مسجلاً بدقة `1080p` للسيناريو الكامل (مدته 3 دقائق) كنسخة احتياطية أخيرة على سطح المكتب في حال تعطل جهاز العرض. |
