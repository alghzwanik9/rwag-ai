# دليل تشغيل Graphify (قرافي فاي)

أداة Graphify تقوم بإنشاء خريطة معرفية (Knowledge Graph) للمشروع، مما يسهل البحث عن الأكواد وفهم البنية الهيكلية والعلاقات بين الملفات.

## الأوامر الأساسية

### 1. تحديث أو إنشاء الخريطة (Graph)

استخدم هذا الأمر لتحديث الخريطة بعد إجراء أي تعديلات على الأكواد.

```bash
graphify update .
```

### 2. الاستعلام وطرح الأسئلة

استخدم هذا الأمر لطرح أسئلة حول الكود أو هيكلية المشروع. سيقوم بإرجاع جزء محدد من الخريطة للإجابة على سؤالك.

```bash
graphify query "سؤالك هنا"
```

*مثال:*

`graphify query "how does user authentication work?"`

### 3. البحث عن المسار (العلاقة بين ملفين أو عنصرين)

يستخدم لمعرفة العلاقة أو الارتباط بين عنصرين (أو ملفين) في النظام.

```bash
graphify path "العنصر_الأول" "العنصر_الثاني"
```

*مثال:*

`graphify path "LoginComponent" "AuthService"`

### 4. شرح مفهوم أو عنصر معين

استخدم هذا الأمر لفهم تفصيلي لعنصر أو مفهوم محدد داخل المشروع.

```bash
graphify explain "المفهوم_أو_العنصر"
```

*مثال:*

`graphify explain "DatabaseConnection"`

---
